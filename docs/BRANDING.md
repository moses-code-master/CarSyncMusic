## Visual identity

Use the sound-wave mark, dark background `#0C1017`, lime accent `#B4F36D`, and clear white type. Keep the launcher label **CarSync Music**. The launcher mark has no small text; creator attribution appears in the launch wordmark, persistent app header, Home welcome card, About screen, README and release documentation.

The icon includes a legacy vector, adaptive versions on Android 8+, and a monochrome layer on Android 13+. Launch resources include the outlined **CarSync Music / by Brayo** wordmark for legacy launch windows and Android 12+ system splash screens. No font file, image service or new runtime dependency is required. The committed wordmark is generated by `scripts/generate-brand-wordmark.ps1` on Windows; ordinary builds use the committed vector directly.

Runtime identity strings live in `CreatorBrand.kt`. About reads the version from the generated BuildConfig. Gradle copies the root LICENSE into APK assets so the in-app license remains identical to the source license.

## Copyright recommendation

The previous MIT notice was `Copyright (c) 2026 CarSync Music contributors`. Retain it. This PR proposes adding `Copyright (c) 2026 Brayo` as a separate notice for Brayo's contributions rather than replacing contributor attribution. Use the actual rights holder's name if that differs from the creator name supplied here. Creator/maintainer credit and copyright ownership serve different purposes.

The MIT permission and warranty text remain intact. Third-party dependency notices and the original test audio's CC0 notice are retained. The [MIT license](https://opensource.org/license/mit) requires its copyright and permission notices to accompany copies or substantial portions of the software.

## Release practice

Use `.github/RELEASE_TEMPLATE.md` for future official release notes. Identify the release as **CarSync Music — by Brayo**, include the creator/contact/profile, and distinguish a review candidate from a published release. Do not rewrite historical releases or remove their notices. Version 1.4.0 is a PR candidate until approved and merged; the README's existing APK download remains the published 1.3.1 release.

The Android application ID remains `app.carsync.music`. Signing uses the existing private GitHub Actions test key; no keystore or credential belongs in source control. CI checks both clean installation and an in-place update from the signed 1.3.1 APK on Android 6, 8 and 15. No playback/backend changes or paid services are part of this branding update.
