# CarSync Music 1.6.0 — multiple guests

Created and maintained by Brayo. One host can now share a session with up to **10 guests** (11 devices in total).

## Use it

1. Install the same 1.6.0 APK on the host and guests. The app identity and persistent signing key are preserved for updates from 1.1 and later.
2. Use the same server address on every device: `https://carsync-music.onrender.com`.
3. The host creates one session. Every guest joins using that same six-digit code or QR invitation.
4. The host chooses music and taps **Share music with guests** for MP3s they have permission to share. A song uploads once and all guests can stream that stored copy. Guests with matching local files play locally instead.
5. Open **Connected Cars** to see everyone, online guest count, registered places used, and each car's estimated player drift.
6. Host-only playback controls remain the default. Enabling **Guest playback controls** grants control to all guests; their play/pause/seek/skip commands affect the entire group.

The host's sharing consent covers all session guests, including guests who join later. Revoking sharing stops remote audio for all guests. Local matching files remain available. Each guest has an independent authentication token; reconnect uses its existing place. Registered guests, including offline guests, reserve their places until the session expires or the host ends it. Create a fresh session if all places are used by devices that lost their credentials.

## Deployment and limits

The server defaults to ten guests. Self-hosted deployments can set `MAX_GUESTS` to an integer from 1 to 50; this is a capacity setting, not a performance guarantee. Shared audio uses server outbound bandwidth per listener, even though the host uploads only one copy. The existing free-hosting sleep/storage/usage limits remain, and larger groups may require better connectivity or hosting. No paid resources are selected by this update.

The existing video features and parked-picture restrictions are preserved. Video still requires an identical local file on every device; video relay remains disabled. Audible alignment on separate physical head units still needs device testing; player timelines and emulator results do not measure speaker/Bluetooth latency.
