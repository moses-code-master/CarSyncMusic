# CarSync Music by Brayo 1.9.3 (build 27)

Release foundations built on 1.9.2, retaining the 1.9.1 convoy, location, radio, Bluetooth, calibration and collaborative media features.

## Added

- Android 16/API 36 target; Android 6/API 23 minimum retained.
- Separate internal/test and Play upload signing configurations, signed AAB output, R8 code shrinking and resource shrinking.
- Audio-only MediaLibraryService browsing, pagination, search, media-search intent handling and resumption for Android Auto. Trusted car display connections enable driving restrictions and block video.
- Offline privacy notice, public backend privacy endpoint, explicit GPS-sharing disclosure before permissions, and optional local crash reports with clear/export controls. No cloud analytics/advertising SDK was added.
- Larger 72 dp primary controls and simplified driving navigation.
- Automatic host handover after a 45-second disconnect for updated hosts and capable guests, with role persistence and original credential preservation.
- Intercom speaker/ducking recovery for a car joining during a transmission.

## Verified November 5, 2026

- Full backend suite: 41 tests passed, including mixed-codec voice, late-join speaker recovery, ten-car fanout, host election/grace/legacy compatibility, role persistence, upload recovery and privacy endpoint checks.
- Android JVM unit suite: 61 tests passed, 0 failures/errors.
- Internal and Play release builds, signed AAB, release lint and Android integration-test APK compilation succeeded.
- Play lint: 0 errors and 48 warnings. Warnings remain; they are not all resolved in this candidate.
- Internal APK metadata: `app.carsync.music`, version 1.9.3, code 27, target/compile SDK 36, minimum SDK 23.
- Internal APK signing certificate matches the supplied 1.9.1/1.9.2 test builds. APK signature and ZIP alignment checks passed. Packaged privacy text matches the backend notice byte-for-byte.
- Native libraries for ARM64, ARMv7, x86 and x86-64 have 16 KB ELF load alignment. Bundle configuration specifies 16 KB page alignment.
- Signed upload bundle validates with official bundletool 1.18.3; its production upload certificate differs from the internal test certificate. JAR signature verification passed after archive-order normalization, with all signed entry payloads preserved.
- The universal internal APK is 3,229,918 bytes, approximately 72.8% smaller than the previous 1.9.2 APK.
