# CarSync Music v1.9.0 — Android production release

## Changes
- Playback continuity correction to reduce scratching from aggressive synchronization seeks
- GPS/network-provider updates, map marker freshness, reconnection behavior and independent per-car opt-in location controls
- Full convoy roster, location age and map following
- Compact voice intercom, user-initiated Bluetooth call-audio support and synchronization telemetry
- URL validation, HTTPS enforcement for public server addresses, and redirect blocking for authenticated requests

## Server routing
New installs use `https://carsync-music.onrender.com`, the production server. On upgrading from v1.9.0-beta.6, a live session stays on its existing endpoint. Manually configured test or LAN URLs stay untouched. When an inactive client leaves an automatically chosen beta endpoint, the app uses the production server for the next session. Different servers do not share session codes, uploaded tracks, or GPS rosters. Keep every phone within one convoy on the same URL.

## Verified
A test user reported that music, intercom, live convoy map and reconnect functioned on physical devices. This is user-reported acceptance, not an independently measured acoustic or GPS accuracy report. Final GitHub CI must pass at the exact production branch SHA before merger. Deployment to Render may restart sessions if the free service restarts and storage is not persistent.

## Install
Build `assembleRelease` through GitHub Actions, download the `CarSyncMusic-release-apk` artifact and install `app-release.apk` on Android 6.0 or later. Builds use the project's configured Android signing key. Do not claim Google Play distribution or Play Store signing.

## Release safeguards
Production deployment is tied to merge into `main`; old active sessions may be affected. Test server remains available at `https://carsync-music-map-test.onrender.com` for isolated validation. Preserve credentials and do not reuse an active beta session's numeric code on a different server.
