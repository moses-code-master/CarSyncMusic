# CarSync Music v1.9.1 — Automatic production server

- New installations use the built-in CarSync cloud server: `https://carsync-music.onrender.com`.
- Users do not need to type a server address. Tap **Create session** on one phone, then **Join session** on the second.
- Existing inactive installations migrate automatically off the three retired official beta URLs, even if a previous beta asked users to save that server manually.
- An active session is never migrated across servers mid-playback. **Leave the old session** on both phones and create a new one; old six-digit codes cannot move between independent server installations.
- Deliberately configured custom HTTPS servers and local HTTP relays continue to work.
- Settings now includes **Use automatic CarSync server** (one tap). The server URL entry is explicitly optional/advanced.
- The intercom error message points to the automatic production server, rather than the retired test server.
- Production sessions require internet access. Intercom, live GPS and voting are features advertised by the server after connecting. GPS sharing requires the device holder's explicit opt-in, even when the server is automatic.

## Build and installation
Version 1.9.1 (versionCode 25), compatible with Android 6.0 and later. GitHub Actions builds `app-release.apk` using the repository's existing signing configuration. Install over 1.9.0 if Android confirms the signatures match; otherwise do **not** uninstall without first exporting or backing up any files and settings you need.

## Checks
The release must pass Android compilation, unit tests, emulator playback on API 23/26/35, and backend tests on its exact commit. The production backend itself remains unchanged in this client-only release.
