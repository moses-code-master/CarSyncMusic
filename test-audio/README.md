# Original test audio

Two 45-second mono MP3s with a brief tone pulse every second: 880 Hz and 660 Hz. Generated specifically for this project, dedicated to the public domain under CC0. They are test signals, not music; start at low volume.

Copy the exact same files to both devices and import them with CarSync. Compare matching pulses in a shared stereo recording to measure audible synchronization. Use the second track for skip, repeat and playlist tests. Encoder padding introduces a small leading delay that is identical for exact file copies. These files do not establish measured synchronization results on any physical devices.
